# SVD Xtend

Video frame interpolation and video continuation with Stable Video Diffusion.

| Project | Description |
| --- | --- |
| [SVD Interp](svd_interp/README.md) | Generate a video sequence conditioned on start and end images. |
| [SVD Extend](svd_extend/README.md) | Extend video through clip continuation, initial-image conditioning, and latent overlap. |

Each project maintains its own pipeline, Conda environment, configuration, and usage instructions. Run commands from the corresponding project directory.

Model weights and local outputs are stored separately and are not included in the repository.
